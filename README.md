# House Prices - Advanced Regression Techniques.

A Machine Learning regression project based on Kaggle's
House Prices - Advanced Regression Techniques competition.

## Objective

The objective of this project is to predict the sale price
of residential properties in Ames, Iowa, using various
property characteristics.

## Dataset

The dataset contains information about residential properties
including features related to quality, area, location,
garage, basement, and other characteristics.

Source:
Kaggle - House Prices: Advanced Regression Techniques

## Project Workflow

1. Data Loading
2. Data Understanding
3. Missing Value Analysis
4. Data Cleaning
5. Exploratory Data Analysis
6. Feature Engineering
7. Categorical Encoding
8. Model Training
9. Model Comparison
10. Prediction
11. Kaggle Submission

## Machine Learning

This project focuses on regression techniques for predicting
house prices.

## Kaggle Result

Final Kaggle submission score:

0.13590
